# 率土之滨模拟助手

网易率土之滨游戏爱好者，课余时间完成的一个率土之滨模拟助手程序。（程序内部对局数据为自己收集，不确保完全正确，仅供参考）

具有以下功能：

- 武将数据记录和战法记录
- 多用户模式，可在任意用户存档之间切换
- 模拟配队，搭配武将和战法
- 模拟对战板块，提供保存队伍模板和灵活加点，调整等级和进阶兵种，图像化战报更加直观。
